# Frontend design

Read [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md) before designing or changing web UI in
this project. Follow its established conventions and use its guidelines as
defaults. User instructions take precedence.

When user feedback or implementation reveals a reusable design decision, update
the relevant section and decision log in the same task. Distinguish established
choices from experiments and unresolved gaps. Keep updates proportionate to the
requested change.
